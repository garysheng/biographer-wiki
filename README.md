# biographer.wiki

A reference wiki on collecting a person's life story with AI agents: the ontology and context that make a life story capturable.

- **Live:** https://biographer.wiki (Vercel project `biographer-wiki`)
- **Maintainer:** Gary Sheng (sole owner)
- **Mode:** authored-canon. The wiki grows by authoring original thinking that coheres with the existing canon, in the wiki's voice. Intake procedure: `static/skills/biographer-intake/SKILL.md`, served at https://biographer.wiki/skills/biographer-intake/SKILL.md.

## What this wiki argues

The mechanism of collection matters less than the ontology: transcripts, characters, moments, a timeline that grows, and the forms a biography projects into. Context collection is the craft. Not overengineering the ontology is the discipline.

## Local dev

```bash
pnpm install
pnpm run start -- --port 4444   # dev server
pnpm run build                  # prod build, enforces onBrokenLinks: throw
```

Pushing to `main` auto-deploys to production via Vercel.

## Repo layout

- `docs/start-here/index.mdx` — homepage (`slug: /`)
- `docs/concepts/` — the lexicon (autogenerated sidebar)
- `docs/principles/` — the discipline (autogenerated sidebar)
- `docs/ontology/` — the shapes of a captured life (autogenerated sidebar)
- `docs/reference/` — tools, glossary, voice rules
- `illustrations/` — self-contained hero pipeline (`render-hero.sh`; register lives in `wiki.config.json` `hero_register`)
- `static/skills/biographer-intake/` — the hosted intake skill
- `wiki.config.json` — title, tagline, URL, posture, hero register

## Pitfalls worth knowing

- `onBrokenLinks: throw` fails the build on any broken internal link. Use absolute paths (`/concepts/<slug>`).
- The wiki is noindex plus bot-blocked (`middleware.ts`); `skills/` and `generators/` paths are carved out so agents can fetch the hosted skill.
- A local build rewrites `src/data/changelog-events.json`; commit it so `/changelog` shows full history in production.
- No em dashes anywhere. Voice rules: `docs/reference/voice-rules.md`.
